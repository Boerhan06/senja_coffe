# ☕ Senja Coffee — Website Resmi

Website landing page modern untuk **Senja Coffee**, sebuah kedai kopi dengan suasana hangat dan nyaman. Dibangun menggunakan React + Vite dengan tampilan yang elegan dan responsif.

---

## 🖥️ Tampilan

Website ini terdiri dari beberapa bagian utama:

- **Navbar** — Navigasi responsif dengan efek scroll
- **Hero** — Halaman utama dengan visual yang menarik
- **About** — Cerita dan filosofi Senja Coffee
- **Menu** — Daftar menu minuman dan makanan unggulan
- **Gallery** — Galeri foto suasana kedai
- **Testimonials** — Ulasan dari pelanggan setia
- **Location** — Informasi lokasi dan jam operasional
- **Footer** — Tautan sosial media dan informasi kontak
- **WhatsApp Button** — Tombol cepat untuk menghubungi via WhatsApp

## 🚀 Cara Menjalankan Secara Lokal

Pastikan kamu sudah menginstall [Node.js](https://nodejs.org/) versi terbaru.

### 1. Clone repositori ini

```bash
git clone https://github.com/Boerhan06/senja_coffe.git
cd senja_coffe
```

### 2. Install dependensi

```bash
npm install
```

### 3. Jalankan development server

```bash
npm run dev
```

Website akan berjalan di `http://localhost:5173`
